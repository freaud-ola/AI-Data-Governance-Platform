## v1 → v2 主要变更摘要

1. 复用开源底座（OpenMetadata / OpenLineage / Great Expectations），把团队精力留给差异化。
2. 治理域补齐：新增**数据标准、指标管理、主数据、生命周期与成本治理**。
3. AI 升级为"操作系统"而非"工具"：工业级 NL2SQL、Agent + MCP、LLMOps 完整闭环。
4. 安全合规从空白补齐：数据分级分类、静/动态脱敏、SSO + RBAC/ABAC、审计、合规导出。
5. 路线图重排：智能注释生成 / 语义搜索前置到 Phase 1-2，3 个月内可见 MVP 价值。
6. 技术细节修正：HMS 直连、OpenSearch 替代 ES8、湖仓 (Iceberg/Hudi) 与 dbt/调度元数据接入。

完整变更说明见 [`00-总体规划-v2.md` 第 1.3 节](./00-总体规划-v2.md#13-v1--v2-主要变更)。

## 文档约定

- 架构图统一使用 **Mermaid**（GitHub / IDE 直接渲染），尽量不用 ASCII 框图。
- 配置示例统一使用 **YAML**，禁止使用 JSON 注释等不规范写法。
- 所有跨文档引用使用相对链接 `./XX-xxx.md#section`。
- 命名约定：模块用中文 + 英文括号（如 `元数据中心 (Metadata Hub)`），代码示例保留英文。
