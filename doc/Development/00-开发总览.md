## 四、快速上手

### 前置依赖

| 工具 | 最低版本 | 当前本机 |
|---|---|---|
| Node.js | 18+ | ✅ 22.14.0 |
| Python | 3.11+（`pyproject.toml` / 推荐） | 请用 3.11+ 创建 venv（SQLAlchemy 2 映射注解依赖） |
| npm | 9+ | ✅ 11.4.2 |

### 一键启动（推荐）

```bash
# 本机模式（venv + uvicorn + vite）
./start.sh

# Docker 模式（含 PostgreSQL + Redis 基线）
cp .env.example .env
./start.sh --docker
```

### 测试 / Lint / 构建（提交前自检）

```bash
# 后端
cd backend && pip install -r requirements.txt -r requirements-dev.txt && pytest -q   # 26 用例 smoke

# 前端
cd frontend
npm run lint:strict                      # 0 warning
npm run typecheck
npm run build
```

### 关键 URL

| 入口 | URL |
|---|---|
| 前端 | http://localhost:5173 |
| 后端 Swagger | http://localhost:8000/docs |
| 后端健康检查 | http://localhost:8000/health |
| PostgreSQL（Docker 模式） | localhost:5432  user=adg db=adg |
| Redis（Docker 模式） | localhost:6379 |

## 七、下一次开发该看什么

> 如果你（或下一位接手人）下次再来开发，从这里开始：

1. **先看本文件**：理解当前进度。
2. **再看最新一期 Sprint 文档**：[`03-Sprint03-持久化层.md`](./03-Sprint03-持久化层.md) — 看"下次接续点"。
3. **本地复跑一次**：按 [快速上手](#四快速上手) 启动前后端，确认 `pytest -q` 26 绿、`npm run lint:strict` 0 warning；`./start.sh --docker` 时 `/health` 中 `persistence` 应为 `postgres`。
4. **挑下一个工作项**：Sprint 03 收尾（CI、`pytest-cov`、可选 PG 集成测）与 Sprint 04（OpenMetadata 等）按 [`03-Sprint03-持久化层.md`](./03-Sprint03-持久化层.md) §四 与 [Architecture/06 §Phase 1](../Architecture/06-开发路线图与风险.md#phase-1m1-2基础底座--mvp) 推进。
